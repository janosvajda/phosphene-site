# Phosphene

Phosphene listens to whatever your Mac is playing and turns it into an endless
stream of visuals that move with the music in real time. It travels through 31
visual plugins, from 3D worlds and particle storms to line art. One plugin
invents its own images and keeps evolving them with the music, so what you see
never repeats.

This repository hosts the app's public [support](support.md) and
[privacy policy](privacy.md) pages.
